Классификация и идентификаторы процессов

С — сквозной: проходит через несколько отделов
Л — локальный: происходит внутри одного отдела
О — основной: основной, системообразующий процесс
П — поддерживающий: вспомогательный: инфраструктура и ресурсы
У — управленческий: координация, контроль, целеполагание
И — инновационный: качественное изменение бизнеса
Коды можно сочетать: ОС1 — основной сквозной, ПЛ6 — поддерживающий локальный. Номер в коде — порядковый номер процесса; дочерний процесс — через точку (ОЛ2.1).

Координатор клиента

Роль, а не подразделение. Единственный канал данных с клиентом (кроме отдела судебно-претензионной работы и направления счетов/актов Главным бухгалтером). Один координатор на клиента; при нескольких услугах — по приоритету направлений.

ДопущениеСквозные процессы показаны ролями, без численности и реальных наименований отделов. Должности: Руководитель <направления>, Начальник отдела <отдела>, Специалист <ведущий/1/2 категории>.
ДопущениеКоординатор клиента назначается для каждого клиента (в т. ч. при одной услуге) и является единственным каналом данных с клиентом. Это роль специалиста направления с наивысшим приоритетом услуг, а не отдельная должность.
ДопущениеИсключение: до заключения и при изменении договора с клиентом общаются продажи (ОЛ4, ПС5); все вопросы сопровождения — только координатор, кроме отдела судебно-претензионной работы (ОЛ2.5), который общается с клиентом напрямую, и Главного бухгалтера, направляющего клиенту счета и акты (ПЛ7). Отдел сопровождения взыскания задолженностей (ОЛ2.4) работает по «единому окну». Жители (получатели услуг клиента-УК) клиентом не являются: обращения жителей решает РЦ.
ДопущениеРабочие дни — по производственному календарю РФ. Сроки из презентации — это готовность ответа/действия.
ДопущениеВзыскание задолженности за ЖКУ (ОЛ2.4) включает работу с судом и выполняется условно автоматизированно. В отдел судебно-претензионной работы (ОЛ2.5) дело передаётся только если суд не принял исковое заявление в первой редакции и требует уточнений.
ДопущениеПри передаче дела из ОЛ2.4 в ОЛ2.5 клиента информирует координатор. ОЛ2.5 сообщает координатору только об окончании работ; прочая коммуникация — с клиентом напрямую.
ОткрытоОЛ2.4 (взыскание задолженностей по ЖКУ) будет доработан позже: действия после принятия иска судом, документы и сроки отдела.
ДопущениеЮридическое направление (ОЛ2.4, ОЛ2.5) и продажи (ОЛ4) показаны заготовками: только согласованные точки входа/выхода, внутренние функции и сроки не домысливались.
ДопущениеПЛ7 «Выставление счёта и оплата услуг»: владелец — Главный бухгалтер; счёт и акт клиенту направляет он сам (исключение из правила координатора); ответ клиента (оплата, подписанный акт) — тоже ему, это моё допущение для подтверждения. Добавлены мной: ветка «данные не соответствуют договору → уточнить данные у координатора», шаг подтверждения завершения Главным бухгалтером, предложенные сроки (Н). Координатор может быть из другого направления — это интерфейс процесса, класс «локальный» сохранён.
ДопущениеКлассы присвоены так: ОС — приём, обслуживание, прекращение; ОЛ — бухгалтерия, ГИС, РЦ, юристы, привлечение (владелец — одно направление); ПС — изменение состава услуг; ПЛ — передача дел (внутри отдела). Привлечение клиента — ОЛ подтверждено (юристы не участвуют). Передача дел — ПЛ подтверждено (внутри отдела).
ДопущениеПроцессы, убранные из набора (внутренний запрос, эскалация, ошибки, претензии, контроль качества, дисциплина), сохранены в резерве и в истории репозитория; предлагаемый класс — У. Нормативы из презентации по ним остаются в таблице сроков.
ДопущениеСроки «Н» (предложены) введены только там, где в документации срок не определён. Эскалация по времени (просрочка → уровень) не вводилась.
ДопущениеХранение документов и сроки — значения по умолчанию из норм РФ и практики; формы и шаблоны документов не утверждены.
