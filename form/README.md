# Приём показаний ХВС/ГВС с сайта на Tilda

Форма на Tilda → Google Apps Script → Google Таблица (оттуда копируется в 1С).

## Установка (≈15 минут)
1. Создайте Google Таблицу. **Расширения → Apps Script**, вставьте `apps_script.gs`, сохраните.
2. Запустите функцию `doGet` один раз и разрешите доступ — создадутся листы «Настройки», «Лицевые счета», «Показания», «Журнал».
   В **Файл → Настройки таблицы** проверьте часовой пояс.
3. **Справочник счетов.** Откройте лист «Лицевые счета» → очистите его → **Файл → Импорт → Загрузка** `accounts.csv` →
   «Заменить текущий лист», разделитель «Точка с запятой» (если спросит — не преобразовывать текст в числа).
   Должны остаться два столбца: «Лицевой счёт» и «Помещение».
4. **Развернуть → Новое развёртывание → Веб-приложение**: выполнять от своего имени, доступ — «Все». Скопируйте URL (`.../exec`).
5. В Tilda: блок **T123 «HTML»**, вставьте `tilda_block.html`, в `URL_API` подставьте URL, опубликуйте страницу.
   После любой правки скрипта — **Управление развёртываниями → Изменить → Новая версия**.

Если вы ставили прошлую версию: удалите старый лист «Показания» (изменились столбцы), он создастся заново.

## Как работает форма
* Вводится лицевой счёт (12 цифр, в базе есть и один 13-значный). Начиная с 12-й цифры форма спрашивает у скрипта и показывает «Квартира N».
  Для помещений без номера квартиры показывается «Помещение САС» — первые буквы ФИО владельца счёта (без расшифровки).
  Квартира выдаётся только при полном совпадении с листом «Лицевые счета»; список счетов на сайт не передаётся.
  Пока квартира не определилась, кнопка «Отправить» неактивна; сервер проверяет счёт повторно.
* ХВС и ГВС приводятся к виду `27,124`: до 5 цифр, запятая, 3 знака (`144` → `144,000`, `59.01` → `59,010`).
  Буквы и лишние знаки блокируются, неверное значение — «Проверьте подлинность значения».
* «Добавить прибор учёта» создаёт вторую строку (максимум 2). Когда строк две, у каждой нужно выбрать «ванна» или «кухня»,
  места должны различаться — иначе отправить нельзя (проверяется и на сервере).

## Окно приёма
Лист «Настройки», столбец B: день начала, день окончания (включительно), «Приём включён» (ДА/НЕТ), текст при закрытом окне.
Если день окончания меньше дня начала (28 и 3) — окно переходит через границу месяцев; показания 1–3 числа записываются
в предыдущий период.

## Данные для 1С
Лист «Показания»: Период | Лицевой счёт | Квартира | Место | ХВС | ГВС | Принято | Примечание. Значения хранятся текстом
с запятой (`27,124`). Повторная отправка за месяц заменяет строки этого счёта. Примечание отмечает показание меньше прошлого месяца.
«Журнал» — все отправки подряд.

## Обновление справочника счетов
```bash
python3 build_accounts.py выгрузка_1с.xlsx accounts.csv
```
Скрипт берёт счёт из столбца «Лицевой счёт» (до запятой, 12–13 цифр) и помещение из «Жилое помещение» (после третьей запятой);
если номера квартиры нет (или «кв. 0») — «Помещение » + инициалы владельца. Полные имена в файл не попадают. Затем снова загрузите CSV в лист «Лицевые счета».
Не открывайте таблицу на редактирование посторонним: там персональные данные.
