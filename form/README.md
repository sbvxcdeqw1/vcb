# Приём показаний ХВС/ГВС с сайта на Tilda

Форма на Tilda → Google Apps Script → Google Таблица (оттуда копируется в 1С).

## Установка (≈10 минут)
1. Создайте Google Таблицу. **Расширения → Apps Script**, вставьте содержимое `apps_script.gs`, сохраните.
2. Запустите функцию `doGet` один раз и разрешите доступ — создадутся листы «Настройки», «Показания», «Журнал».
   В **Файл таблицы → Настройки** проверьте часовой пояс (например, Москва).
3. **Развернуть → Новое развёртывание → Веб-приложение**: выполнять от своего имени, доступ — «Все». Скопируйте URL (`.../exec`).
4. В Tilda: добавьте блок **T123 «HTML»**, вставьте `tilda_block.html`, в `URL_API` подставьте URL. Опубликуйте страницу.
   Код изменили в Apps Script — делайте **новое развёртывание/новую версию**, иначе работает старый.

## Окно приёма
Лист «Настройки», столбец B: день начала, день окончания (включительно), переключатель «Приём включён» (ДА/НЕТ),
число квартир, текст при закрытом окне. Меняется на лету. Если день окончания меньше дня начала (например, 28 и 3), окно переходит через границу месяцев; показания, поданные 1–3 числа, записываются в предыдущий период.
Шрифт формы — Montserrat (подключается из Google Fonts).
Вне окна форма показывает сообщение и кнопка неактивна; сервер дополнительно отклоняет отправку.

## Данные для 1С
Лист «Показания»: Период | Квартира | ХВС | ГВС | Принято | Примечание. Одна строка на квартиру за месяц:
повторная отправка в том же месяце обновляет строку. Примечание отмечает показание меньше прошлого месяца.
Выделите нужные столбцы и копируйте в 1С. «Журнал» — все отправки подряд.

Не забудьте: не раздавайте таблицу на редактирование посторонним (там персональные данные).
