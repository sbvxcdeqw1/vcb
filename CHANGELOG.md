# История версий

Нумерация `ГЛАВНАЯ.ФУНКЦИИ.ИСПРАВЛЕНИЯ`: новая возможность — вторая цифра, исправление — третья.
Архив для скачивания называется `vcb-<версия>.zip`; версия видна в заголовке окна и по `vcb --version`.

## 0.7.0 — 2026-10-30
- Ручной зачёт платежей: в окне («Один должник») после выбора реестра оплат появляется список платежей с галочками.
  Программа заранее отмечает свои решения (исполнительное производство — не в зачёт); любую галочку можно поставить
  или снять, кнопки «Зачесть все», «Не зачитывать все», «Как решила программа». Пересчёт учитывает изменения.
- Командная строка: `--payment-overrides` и `--cap-payment-overrides`; csv `дата;сумма;решение;комментарий;номер`
  (сумма `*` — любой платёж даты, номер — порядковый среди одинаковых платежей).
- В замечаниях: сколько платежей зачтено и не зачтено и сколько решений принято вручную.

## 0.6.2 — 2026-10-30
- Реестр оплат по капитальному ремонту (столбцы «Номер», «Дата вх.», «Сумма», «Информация»): читается по
  названиям столбцов; платежи «Погашение долга … Исполнительный лист» распознаются как исполнительное производство
  и в зачёт не берутся.
- Лицевой счёт с буквой («К05») сопоставляется с записью в реестре цифрами с нулями («00000005»).

## 0.6.1 — 2026-10-30
По образцу шахматки капитального ремонта (лицевой счёт с буквой, ФИО собственника в шапке, строка «Пени», адрес без «г.»):
- строка «Пени» шахматки больше не считается услугой и долгом: пени пересчитываются заново (в замечаниях указано, что
  из шахматки исключено); в списке услуг она не показывается;
- ФИО собственника берётся из шапки шахматки, лицевой счёт с буквами поддерживается при отборе платежей реестра;
- адрес вида «ПЕРМЬ, ул.Название, д.1, кв. 2» разбирается на город, улицу, дом и квартиру;
- если участок мирового судьи по адресу не определяется однозначно (дом внутри описанной границы), в замечаниях
  перечислены участки-кандидаты, районный суд определяется, если все кандидаты одного района; участок можно задать
  вручную в поле «Участок мирового судьи» (колонка `court` реестра должников);
- в карточке расчёта по капремонту: «Начисление взносов», вместо повтора заголовка — лицевой счёт.

## 0.6.0 — 2026-10-30
Два пакета документов: жилищно-коммунальные услуги и капитальный ремонт.
- В окне две вкладки («Жилищно-коммунальные услуги», «Капитальный ремонт»): у каждой свои шахматка, реестр оплат
  и список услуг с галочками. Можно заполнить один пакет или оба; в пакетном режиме шахматки ЖКУ и капремонта одного
  должника сопоставляются по адресу квартиры (лицевые счета у них разные).
- Логика расчёта у пакетов одна: разноска оплат, пени, карточка, шахматка. Для капремонта пени — по ч. 14.1 ст. 155
  ЖК РФ: 1/300 ставки с 31-го дня без перехода на 1/130 (`penalty.caprepair` в настройках); срок оплаты — до 10 числа.
- Суммы пакетов объединяются: цена иска, госпошлина, вид документа (приказ или иск) и суд определяются по общей сумме.
- Заявление/иск — один документ на оба пакета: заголовок, ссылки на ст. 155 (ч. 14 и/или 14.1) и ст. 169 ЖК РФ,
  долг и пени по каждому пакету с его периодом, одно общее требование, перечень приложений по каждому пакету
  (для капремонта — копия протокола общего собрания).
- По каждому пакету свои файлы: Шахматка_с_учетом_оплат_<ЖКУ|капремонт>.xlsx, Карточка_расчета_…, Расчет_пени_….
- Командная строка: `--cap-input`, `--cap-payments`, `--cap-exclude-services`.

## 0.5.0 — 2026-10-30
- Шахматка полностью переработана для печати: всё на одном листе, A4 вертикально. Месяцы идут слева направо по четыре
  в блоке («Начислено» / «Оплата»), дальше переносятся блоками на новую строку; у каждого блока своя шапка и строка
  «Итог». В конце — сводный блок «Итого за период» по услугам (начислено, оплата, задолженность) и подпись. Блоки не
  разрываются между страницами. Листы по годам убраны: детализация по всем месяцам на одном листе.

## 0.4.0 — 2026-10-29
Новая логика подачи документов: на входе шахматка и реестр оплат, на выходе шахматка с учётом реестра оплат,
карточка расчёта и расчёт пени.
- Начисления берутся из шахматки. Список услуг читается из файла до расчёта, в окне у каждой услуги галочка:
  снятые услуги в расчёт не входят (`--exclude-services` в командной строке, колонка `exclude_services` в реестре).
- Оплаты берутся из реестра: на период из назначения платежа, без назначения и остаток сверх периода — на самый
  ранний период с переносом на следующие. Общий реестр банка (файл или папка) отбирается по лицевому счёту.
- Пени считаются по этой разноске (срок оплаты месяца — календарный месяц, ставка ЦБ и потолок, фактические дни).
- «Шахматка с учётом оплат»: оплаты показаны в периодах начислений, по услугам пропорционально начислениям месяца.
- «Карточка расчёта»: тело долга и оплаты без пеней, как в образцах (Дата / Регистратор / Операция / Начислено /
  Оплата / Задолженность, сальдо на начало и конец, обороты); платежи, не вошедшие в расчёт, перечислены под таблицей.
- Заявление в суд и отчёт о разноске оплат — необязательные галочки (`--no-claim`, `--allocation-report`).
- Файлы результата: Шахматка_с_учетом_оплат.xlsx, Карточка_расчета_*.xlsx, Расчет_пени_*.xlsx.

## 0.3.1 — 2026-10-29
- Во всех файлах Excel (карточка долга, расчёт пени, шахматка, разноска оплат) добавлено поле подписи: должность и
  организация, линия подписи с расшифровкой, ФИО представителя из окна программы и строка даты.

## 0.3.0 — 2026-10-29
- Заявление и иск (docx) оформлены по ГОСТ Р 7.0.97-2016: A4, поля 30/10/20/20 мм, Times New Roman 14 пт, интервал 1,15,
  абзацный отступ 1,25 см, реквизиты адресата справа, номера страниц сверху по центру со второй страницы,
  неразрывные пробелы в числах, «№», «ст.», «руб.», подпись не отрывается от текста.
- Таблицы (xlsx): единый шрифт и шапка, заливка заголовков, печать на A4 с повтором шапки таблицы, колонтитулами
  «Страница N из M»; расчёт пени и разноска — альбомная ориентация по ширине страницы; шахматка — страница на
  полугодие с повтором столбцов «Услуга / Начальный остаток», листы по годам помещаются на одну страницу.
- Карточка долга по шахматке свёрнута по датам; в расчёте пени платежи одного дня по разным услугам объединены.

## 0.2.0 — 2026-10-29

  взыскателя, представителя и должника в окне, история введённого.

- Разноска оплат из реестра банковских документов: платежи по исполнительному производству не зачитываются,
  оплата идёт на период из назначения платежа.
- Ключевая ставка ЦБ по датам, потолок 9,5%, моратории; расчётный период задаёт оператор.
- Сверка «Карточки расчётов» с «Шахматкой» (`vcb check`).
