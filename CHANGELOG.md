# История версий

Нумерация `ГЛАВНАЯ.ФУНКЦИИ.ИСПРАВЛЕНИЯ`: новая возможность — вторая цифра, исправление — третья.
Архив для скачивания называется `vcb-<версия>.zip`; версия видна в заголовке окна и по `vcb --version`.

## 0.4.2 — 2026-10-30
- Шахматка печатается на A4 вертикально (масштаб 88%, таблица 9 пт): месяцы с их столбцами «Оплата» целиком
  укладываются на страницу (около 7 столбцов), слева на каждой странице повторяются «Услуга» и «Остаток на начало»,
  итоги — на последней странице; оформление таблицы сохранено.

## 0.4.1 — 2026-10-30
- Из карточки расчёта убрана поясняющая строка про тело долга и источники; из подписи убраны подписи под линией
  «(подпись)» и «(имя представителя)»; заголовок шахматки — «Расчёт начислений и оплат по услугам»; из отчёта о
  разноске убрана поясняющая строка.

## 0.4.0 — 2026-10-29
Новая логика подачи документов: на входе шахматка и реестр оплат, на выходе шахматка с учётом реестра оплат,
карточка расчёта и расчёт пени.
- Начисления берутся из шахматки. Список услуг читается из файла до расчёта, в окне у каждой услуги галочка:
  снятые услуги в расчёт не входят (`--exclude-services` в командной строке, колонка `exclude_services` в реестре).
- Оплаты берутся из реестра: на период из назначения платежа, без назначения и остаток сверх периода — на самый
  ранний период с переносом на следующие. Общий реестр банка (файл или папка) отбирается по лицевому счёту.
- Пени считаются по этой разноске (срок оплаты месяца — календарный месяц, ставка ЦБ и потолок, фактические дни).
- «Шахматка с учётом оплат»: оплаты показаны в периодах начислений, по услугам пропорционально начислениям месяца.
- «Карточка расчёта»: тело долга и оплаты без пеней, как в образцах (Дата / Регистратор / Операция / Начислено /
  Оплата / Задолженность, сальдо на начало и конец, обороты); платежи, не вошедшие в расчёт, перечислены под таблицей.
- Заявление в суд и отчёт о разноске оплат — необязательные галочки (`--no-claim`, `--allocation-report`).
- Файлы результата: Шахматка_с_учетом_оплат.xlsx, Карточка_расчета_*.xlsx, Расчет_пени_*.xlsx.

## 0.3.1 — 2026-10-29
- Во всех файлах Excel (карточка долга, расчёт пени, шахматка, разноска оплат) добавлено поле подписи: должность и
  организация, линия подписи с расшифровкой, ФИО представителя из окна программы и строка даты.

## 0.3.0 — 2026-10-29
- Заявление и иск (docx) оформлены по ГОСТ Р 7.0.97-2016: A4, поля 30/10/20/20 мм, Times New Roman 14 пт, интервал 1,15,
  абзацный отступ 1,25 см, реквизиты адресата справа, номера страниц сверху по центру со второй страницы,
  неразрывные пробелы в числах, «№», «ст.», «руб.», подпись не отрывается от текста.
- Таблицы (xlsx): единый шрифт и шапка, заливка заголовков, печать на A4 с повтором шапки таблицы, колонтитулами
  «Страница N из M»; расчёт пени и разноска — альбомная ориентация по ширине страницы; шахматка — страница на
  полугодие с повтором столбцов «Услуга / Начальный остаток», листы по годам помещаются на одну страницу.
- Карточка долга по шахматке свёрнута по датам; в расчёте пени платежи одного дня по разным услугам объединены.

## 0.2.0 — 2026-10-29
- Окно программы (`vcb_gui.py`): тёмная тема, режимы «Один должник» и «Пакет должников», ввод реквизитов
  взыскателя, представителя и должника в окне, история введённого.
- Справочник судов Пермского края: 38 судов, 146 участков мировых судей, подсудность по адресу квартиры.
- Разноска оплат из реестра банковских документов: платежи по исполнительному производству не зачитываются,
  оплата идёт на период из назначения платежа.
- Ключевая ставка ЦБ по датам, потолок 9,5%, моратории; расчётный период задаёт оператор.
- Сверка «Карточки расчётов» с «Шахматкой» (`vcb check`).

## 0.1.0 — 2026-10-28
- Первая рабочая версия: разбор выгрузок 1С, расчёт долга и пени, заявление (иск / судебный приказ),
  карточки расчёта по ЖКУ и капремонту, шахматка, пакетный режим.
