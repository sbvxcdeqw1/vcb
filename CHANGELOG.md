# История версий

Нумерация `ГЛАВНАЯ.ФУНКЦИИ.ИСПРАВЛЕНИЯ`: новая возможность — вторая цифра, исправление — третья.
Архив для скачивания называется `vcb-<версия>.zip`; версия видна в заголовке окна и по `vcb --version`.

## 0.3.1 — 2026-10-29
- Во всех файлах Excel (карточка долга, расчёт пени, шахматка, разноска оплат) добавлено поле подписи: должность и
  организация, линия подписи с расшифровкой, ФИО представителя из окна программы и строка даты.

## 0.3.0 — 2026-10-29
- Заявление и иск (docx) оформлены по ГОСТ Р 7.0.97-2016: A4, поля 30/10/20/20 мм, Times New Roman 14 пт, интервал 1,15,
  абзацный отступ 1,25 см, реквизиты адресата справа, номера страниц сверху по центру со второй страницы,
  неразрывные пробелы в числах, «№», «ст.», «руб.», подпись не отрывается от текста.
- Таблицы (xlsx): единый шрифт и шапка, заливка заголовков, печать на A4 с повтором шапки таблицы, колонтитулами
  «Страница N из M»; расчёт пени и разноска — альбомная ориентация по ширине страницы; шахматка — страница на
  полугодие с повтором столбцов «Услуга / Начальный остаток», листы по годам помещаются на одну страницу.
- Карточка долга по шахматке свёрнута по датам; в расчёте пени платежи одного дня по разным услугам объединены.

## 0.2.0 — 2026-10-29
- Окно программы (`vcb_gui.py`): тёмная тема, режимы «Один должник» и «Пакет должников», ввод реквизитов
  взыскателя, представителя и должника в окне, история введённого.
- Справочник судов Пермского края: 38 судов, 146 участков мировых судей, подсудность по адресу квартиры.
- Разноска оплат из реестра банковских документов: платежи по исполнительному производству не зачитываются,
  оплата идёт на период из назначения платежа.
- Ключевая ставка ЦБ по датам, потолок 9,5%, моратории; расчётный период задаёт оператор.
- Сверка «Карточки расчётов» с «Шахматкой» (`vcb check`).

## 0.1.0 — 2026-10-28
- Первая рабочая версия: разбор выгрузок 1С, расчёт долга и пени, заявление (иск / судебный приказ),
  карточки расчёта по ЖКУ и капремонту, шахматка, пакетный режим.
