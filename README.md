# vcb — документы для взыскания задолженности по ЖКУ и капремонту

Из выгрузки 1С («Карточка расчетов») и данных должника программа собирает:

1. заявление о выдаче судебного приказа или исковое заявление (`.docx`);
2. карточку расчёта задолженности по ЖКУ и расчёт пени (`.xlsx`, с формулами, как в образцах);
3. то же по взносам на капитальный ремонт (если в выгрузке есть такие начисления);
4. шахматку: начисления/оплаты по назначению платежа, месяцы по горизонтали, лист на каждый год.

## Запуск

```bash
pip install -e . --no-deps && pip install openpyxl python-docx pyyaml xlrd num2words
vcb examples/karta_kv24.xls --profile profiles/example.yaml --as-of 2026-04-13
vcb папка_с_выгрузками/ -r реестр_должников.xlsx --profile profiles/мой.local.yaml -o out
```

* Без `--profile` программа предложит выбрать сохранённый профиль или ввести взыскателя и представителя
  (можно пропустить — в документах останутся пустые поля).
* Пакетный режим: на вход папка с выгрузками; ошибка по одному должнику не останавливает остальных;
  итог — `out/сводка.csv` (долг, пени, госпошлина, вид документа, суд, замечания).
* Реестр должников (csv/xlsx): `file, fio, fio_gen, city, street, house, flat, area, birth_date, birth_place, account, share`.
  Пустые поля берутся из шапки выгрузки. `fio_gen` — ФИО в родительном падеже для «Взыскать с …».

## Как считается

* Долг = начисления периода − оплаты (оплаты гасят самое старое начисление). Строки «Начислено пени» из 1С
  в долг не входят — пени пересчитываются заново.
* Пени — ч. 14 ст. 155 ЖК РФ: 1/300 ставки (31–90 дни), 1/130 (с 91-го дня). Режим `calendar` воспроизводит
  образцы (пени с 11-го числа через месяц после срока; тест сверяет 24 805,47 и 4 351,96 ₽ на 13.04.2026),
  режим `statutory` считает строго по дням. Настройки — `data/config.yaml`.
* Подсудность: судебный приказ ≤ 500 000 ₽ — мировой судья; иск ≤ 100 000 ₽ — мировой судья, выше — районный
  суд (`court.claim_court` позволяет зафиксировать районный суд, как в образцах). Суд — по адресу квартиры
  из `data/courts/<регион>.yaml`.

## Справочник судов

`data/courts/perm_krai.yaml` пока содержит только Кировский районный суд г. Перми (из образца) **без границ
территории**. Границы участков мировых судей и районных судов нужно загрузить из открытых источников
(sudrf.ru, сайт мировых судей Пермского края) — из этой сессии эти сайты недоступны. Пока суд не найден,
в заявлении остаётся пустое место, а в сводке — замечание.

## Не сделано / требует уточнения

* образец заявления на судебный приказ (текст составлен по ст. 124 ГПК РФ, нужна сверка с вашей практикой);
* выгрузка с оплатами и с капремонтом (в образце только начисления услуг);
* ключевая ставка: одна ставка на дату расчёта (как в образцах); история ставок — `key_rates_file`;
* госпошлина и мораторий проверить на дату подачи.
