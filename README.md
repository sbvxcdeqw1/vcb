# vcb — документы для взыскания задолженности по ЖКУ и капремонту

Из выгрузки 1С («Карточка расчетов») и данных должника программа собирает:

1. заявление о выдаче судебного приказа или исковое заявление (`.docx`);
2. карточку расчёта задолженности по ЖКУ и расчёт пени (`.xlsx`, с формулами, как в образцах);
3. то же по взносам на капитальный ремонт (если в выгрузке есть такие начисления);
4. шахматку в формате 1С: услуги по строкам, месяцы по столбцам (Начислено/Оплата), начальный и конечный остаток; лист за весь период и лист на каждый год.

## Запуск с окном (без командной строки)

Двойной щелчок по `vcb_gui.py` (нужен Python 3.10+; на Windows при установке оставьте «tcl/tk and IDLE»).
Недостающие библиотеки программа предложит установить сама. В окне: выгрузка 1С, реестр оплат, реестр должников,
профиль взыскателя/представителя («Реквизиты…»), даты, документ, регион, папка результата → «Рассчитать».

## Запуск из командной строки

```bash
pip install -e . --no-deps && pip install openpyxl python-docx pyyaml xlrd num2words
vcb examples/karta_kv24.xls --profile profiles/example.yaml --as-of 2026-04-13
vcb папка_с_выгрузками/ -r реестр_должников.xlsx --profile profiles/мой.local.yaml -o out
```

* Без `--profile` программа предложит выбрать сохранённый профиль или ввести взыскателя и представителя
  (можно пропустить — в документах останутся пустые поля).
* Пакетный режим: на вход папка с выгрузками; ошибка по одному должнику не останавливает остальных;
  итог — `out/сводка.csv` (долг, пени, госпошлина, вид документа, суд, замечания).
* Реестр должников (csv/xlsx): `file, fio, fio_gen, city, street, house, flat, area, birth_date, birth_place, account, share`.
  Пустые поля берутся из шапки выгрузки. `fio_gen` — ФИО в родительном падеже для «Взыскать с …».

## Входные форматы

Формат определяется по содержимому: «Карточка расчетов» (одна строка на проводку, услуги не разбиты) или
«Шахматка» (разбивка по услугам, оплаты по месяцам с отрицательным знаком). Оплата из шахматки датируется
последним днём месяца — точная дата платежа в выгрузке не указана.

## Разноска оплат

```bash
vcb карточка.xls --payments реестр_банковских_документов.xlsx [--payment-overrides решения.csv]
```

Оплаты берутся из реестра банковских документов (на 20.01.2020–2025 он сошёлся с карточкой 1С до копейки), а не из
строк «Оплата» карточки, где 1С сама делит платёж на долг и пени. Каждый платёж классифицируется по тексту
(`payments.*` в `data/config.yaml`): платежи по исполнительному производству в зачёт не берутся; платежи с
реквизитами бюджетной организации зачитываются как обычные (`payments.third_party_policy: include`); исключаются только платежи по исполнительному производству. Решения по отдельным платежам — csv
`дата;сумма;зачесть|исключить;комментарий`. Зачтённая оплата идёт на период из назначения платежа
(`payments.allocation: purpose`); остаток сверх этого периода и оплаты без периода — на самые ранние начисления
(`oldest` — все оплаты на самые ранние). Оплата за период до начала расчёта не учитывается, оплата за ещё не
начисленный месяц ждёт начисления. Пени пересчитываются по фактическим датам платежей.
Отчёт `Разноска_оплат.xlsx`: какой платёж на какие начисления разнесён, что исключено и почему, сравнение вариантов.

## Сверка выгрузок

```bash
vcb check карточка.xls шахматка.xlsx --merge шахматка_сверенная.xlsx
```

Сравнивает помесячные начисления и оплаты, начальный остаток (в карточке сальдо включает пени) и показывает,
чего не хватает в шахматке. С `--merge` сохраняет шахматку, где разница вынесена отдельной строкой
«Не распределено по услугам», а итоги сходятся с карточкой. Бегущее сальдо карточки проверяется при чтении.

## Как считается

* Долг = начисления периода − оплаты (оплаты гасят самое старое начисление). Строки «Начислено пени» из 1С
  в долг не входят — пени пересчитываются заново.
* Пени — ч. 14 ст. 155 ЖК РФ: 1/300 ставки (31–90 дни), 1/130 (с 91-го дня). Режим `calendar` воспроизводит
  образцы (пени с 11-го числа через месяц после срока; тест сверяет 24 805,47 и 4 351,96 ₽ на 13.04.2026),
  режим `statutory` считает строго по дням. Настройки — `data/config.yaml`.
* Расчётный период задаёт оператор: `--period-from/--period-to` или колонки `period_from`/`period_to` реестра должников
  (иначе — от первого до последнего начисления выгрузки). Расчёт строго по периоду: начисления и оплаты вне него
  не участвуют, периоды «за давностью» входят в расчёт. Автоотбор по давности отключён (`claim.limitation_years: null`).
  Сальдо на начало периода (начальный остаток) в расчёт не входит никогда: ни в долг, ни в очерёдность погашения.
* Подсудность: судебный приказ ≤ 500 000 ₽ — мировой судья; иск ≤ 100 000 ₽ — мировой судья, выше — районный
  суд (`court.claim_court` позволяет зафиксировать районный суд, как в образцах). Суд — по адресу квартиры
  из `data/courts/<регион>.yaml`.

## Справочник судов

`data/courts/perm_krai.yaml` — 38 районных/городских судов и 146 судебных участков мировых судей Пермского края
(адреса, судьи, границы участков: для г. Перми и ряда городов — разобранные списки улиц и домов, для остальных —
текст описания границ). Собран `tools/fetch_courts.py` + `tools/build_courts.py` из sudinforf.ru: это агрегатор, не
закон, поэтому перед подачей проверяйте участок по Закону Пермского края № 453-ПК и изменениям. Кировский
районный суд г. Перми добавлен вручную (`tools/courts_manual_perm.yaml`, адрес из образцов). Подсудность определяется
по адресу квартиры: участок мирового судьи → районный суд участка; если адрес не найден однозначно, в сводке
указываются кандидаты. Другой регион: `fetch_courts.py <регион> <страница-региона> <кэш>` и `build_courts.py`.

## Ставка пени

Ключевая ставка ЦБ на день оплаты (`data/key_rates.csv`, с cbr.ru) с потолком 9,5% (`penalty.rate_cap`); в образцах
заказчика расчёт на 13.04.2026 сходится только с потолком. Мораторий (`penalty.moratoria`) исключает дни из просрочки.
Границы потолка и мораториев заданы по умолчанию по памяти — **проверьте по действующим актам**.

## Не сделано / требует уточнения

* образец заявления на судебный приказ (текст составлен по ст. 124 ГПК РФ, нужна сверка с вашей практикой);
* выгрузка с капремонтом (отдельный образец);
* ключевая ставка: одна ставка на дату расчёта (как в образцах); история ставок — `key_rates_file`;
* госпошлина, потолок ставки и мораторий — проверить на дату подачи.
